## 📘 What the subject covers

> **Fundamentos de Tecnología de Computadores (780002)** · 6 ECTS · 1st year · 1st semester · contents from the 2024-25 teaching guide · [official subject page](https://www.uah.es/es/estudios/estudios-oficiales/grados/asignatura/Fundamentos-de-Tecnologia-de-Computadores-780002/)

| Unit | Hours | Topics |
|---|---|---|
| Introduction | 5 h | Levels of abstraction of a computer · Von Neumann architecture and instruction execution · Performance |
| Number systems | 7 h | Unsigned, sign-magnitude, one's and two's complement · Hexadecimal · Arithmetic in each representation |
| Combinational logic | 18 h | Logic gates, truth tables, Karnaugh maps · Analysis and synthesis of combinational circuits · Adders, decoders, multiplexers |
| Sequential logic | 18 h | Flip-flops · Registers and counters · Design of sequential systems |
| Memory system | 8 h | Memory hierarchy · Address, data and control buses · Memory types and technologies |
